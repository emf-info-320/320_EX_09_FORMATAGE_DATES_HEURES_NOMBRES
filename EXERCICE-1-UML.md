# Exercice 1 : UML

## Objectifs
- Connaître et comprendre les interactions des classes utilisées dans la librairie Java.
- Être capable de dessiner un diagramme de classes UML sur papier ou autre support numérique.

## Données
Effectuez un seul diagramme de classes UML complet dans lequel vous placez les classes `DecimalFormat` et `SimpleDateFormat`.  
Vous devez représenter toutes les relations d'héritage, d'implémentation d'interfaces, jusqu'à la classe `Object`. Dans les classes, vous évitez de représenter les méthodes abstraites, mais vous représentez les constructeurs et une ou deux méthodes concrètes qui vous semblent les plus intéressantes. Les classes sœurs seront également représentées.

## Ressources
Vous avez droit uniquement à la documentation officielle.
- [DecimalFormat](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/text/DecimalFormat.html)
- [SimpleDateFormat](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/text/SimpleDateFormat.html)

## Réalisation & durée
Vous utilisez le support prescrit par votre enseignant pour la réalisation de ce diagramme UML.

Durée : 45 minutes
