# Introduction

De nombreux programmes manipulent des nombre et des dates. Un excellente nouvelle est que la librairie java nous propose des outils pour simplifier le travail de conversion et de modification de la forme visible de ces nombres et de ces dates :

Ces outils, c'est à dire des classes java, vous nous permettrent de répondre aux questions suivantes:

- Comment formater un nombre décimal avec deux chiffres après la virgule ?
  - Afficher 56.20
- Comment formater un nombre avec des séparateurs de milliers ?
  - Afficher 1'265'000
- Comment utiliser des symboles spéciaux dans le format de nombre ?
  - Afficher 12.34%
- Comment formater une date en chaîne de caractères au format "dd/MM/yyyy" ?
  - Afficher 31/05/2024
- et bien d'autres

# Objectifs

-  Comprendre le positionnement dans la librairie java des classes étudiées
-  Identifier les méthodes principales utiles
-  Utiliser le formatage des nombres et des dates dans des situations concrètes
